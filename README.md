# 기어 제너레이터 (Gear Generator)

감속기·기어 형상을 파라미터 몇 개만 입력해서 즉시 생성하는 도구 모음입니다.
브라우저에서 실시간으로 치형을 확인하고 DXF로 내보내는 **웹 생성기 4종**과,
Fusion 360 안에서 3D 솔리드를 바로 만들어주는 **애드인 3종**으로 구성됩니다.

**▶ 웹에서 바로 사용: https://lsk0522.github.io/gear-generator/**

---

## 웹 생성기 (`web/`)

상단 탭으로 생성기를 전환합니다. 모든 탭은 입력을 바꾸는 즉시 SVG 미리보기가
갱신되고, 계산된 파라미터를 사이드바에 표시하며, 성립하지 않는 조합은
경고/오류로 알려줍니다. 공통 조작은 **Ctrl + 휠 = 확대/축소**,
**더블클릭 = 뷰 리셋**, **▶ 재생 = 맞물림 애니메이션**입니다.

### 1. 하모닉 드라이브 (Harmonic Drive)

모듈 / 플렉스스플라인 잇수 `zf` / 서큘러스플라인 잇수 `zc` 를 입력하면
서큘러스플라인 + 플렉스스플라인 + 웨이브제너레이터 캠을 생성합니다.
감속비를 입력하면 `zc` 가 자동으로 따라오므로 원하는 정수 감속비를 정확히
맞출 수 있습니다.

치형은 Yao et al., *"A Novel Cycloid Tooth Profile for Harmonic Drive with
Fully Conjugate Features"*, Actuators 2025, 14(4), 187
([doi:10.3390/act14040187](https://doi.org/10.3390/act14040187)) 의
사이클로이드 치형(CTP)을 구현합니다. 근사식이 아니라 논문의 구성 그대로입니다:

- **이끝 치형** — x-반감 사이클로이드(Eq. 11)를 이빨각 α0 에서 절단(Sec. 3.3).
  절단 파라미터 `tE` 는 이분법으로 풀어서 피치선에서 첨점(cusp) 대신 유한
  반경으로 끝나게 합니다. 이끝 반경은 입력값이 아니라 ha·s0·α0 에서 **자연히
  결정되는 결과값**으로 표시됩니다.
- **이뿌리 치형** — 이끝 치형을 피치점 기준 180° 회전한 점대칭 곡선(Eq. 12).
  임의 필렛이 아니라 논문 그대로이고, 이뿌리 랜드에는 접선 필렛을 피팅합니다.
- **서큘러스플라인 치형** — 파형발생기 한 바퀴 스윕에 대한 **실제 수치
  envelope**(Eq. 14–15). 변형된 플렉스스플라인 이빨이 휩쓰는 영역을 각도 bin
  별 최대반경으로 래스터화해서 공액 치간을 직접 구합니다.
- **파형발생기 변형** — 타원 중립선(Eq. 8, 중립선 비신장 조건으로 단축 b 결정)
  + 단면 회전각 μ = −arctan(ρ′/ρ)(Eq. 4).
- **▶ 재생** — 위와 **동일한 변형 필드**로 플렉스스플라인을 실제로 변형시켜
  맞물림 영역이 링을 따라 도는 것을 보여줍니다 (시각적 근사가 아닙니다).

성능 지표(1차 추정)도 함께 계산합니다: 백래시(기하학적 접촉 탐색),
맞물린 이 개수, 플렉스스플라인 변형률, 스트로크 여유, 이뿌리 랜드 폭 등.

DXF: 서큘러스플라인 · 플렉스스플라인 · 웨이브제너레이터 캠 · 전체(레이어 분리).

### 2. 사이클로이드 감속기 (Cycloidal / Pin-wheel)

감속비 / 핀 피치원 반지름 R / 핀·롤러 반지름 Rr / 편심량 E 를 입력하면
포락선 방식 디스크 외곽선과 핀 배치를 계산합니다. 고급 설정에서 2단
디스크(180° 위상), 편심 축(중앙 축 + 저널), 베어링 보어, 출력핀 구멍,
부위별 공차(디스크–핀 / 보어 / 출력구멍 / 핀)까지 조정할 수 있고, 이는
`CycloidalGearGenerator` 애드인과 동일한 수식·파라미터입니다.

▶ 재생은 편심 입력각에 따른 디스크의 강체 운동(중심이 반지름 E 로 궤도를
돌며 1/(N−1) 속도로 역회전)을 그대로 보여줍니다.

DXF: 디스크 · 핀 링 · 편심 축 · 전체.

### 3. 범용 기어 (Universal)

기어 종류와 감속비·모듈만 입력하면 한 쌍이 생성됩니다.
평기어 / 헬리컬 / 내치 / 베벨 / 웜+웜휠 / 랙-피니언 6종을 지원하고,
압력각과 백래시는 숨기지 않고 슬라이더로 실시간 조정합니다.

치형은 단순 근사가 아니라 **표준 인벌류트**(`involute-math.js`)로 그려서
한 쌍이 간섭 없이 맞물려 회전합니다. 베벨은 2D로 표현할 수 없는 원추
형상이라, 메인 뷰는 축방향 단면(공통 꼭짓점에서 나온 피치원추)으로,
디테일 뷰는 Tredgold 배면원추 등가 평기어(가상 잇수 `zv = z/cos δ`)로
나눠서 보여줍니다.

DXF: 부품 1 · 부품 2 · 전체.

### 4. 유성 감속기 (Planetary)

선기어 · 유성기어 · 링기어 · 캐리어로 구성된 단일 스테이지 유성기어열입니다.
`Zr = Zs + 2·Zp` 구속을 자동 적용하고, 선–유성 외접 / 유성–링 내접 맞물림을
모두 인벌류트로 그려 ▶ 재생으로 실제 유성 운동을 확인합니다.

링 고정 / 선 고정 / 캐리어 고정 3가지 구성의 감속비를 각각 계산하고,
조립 조건 `(Zs + Zr)` 이 유성 개수로 나누어떨어지지 않거나 유성끼리 간섭하면
경고합니다.

DXF: 선기어 · 유성기어 · 링기어 · 전체.

### 로컬 실행

저장소 루트의 `run.bat` 을 더블클릭하면 로컬 서버를 띄우고 브라우저를
자동으로 엽니다 (Python 3 필요). 직접 띄우려면:

```bash
cd web && python -m http.server 8000
```

`master` 브랜치에 `web/` 이 변경되면 `.github/workflows/deploy.yml` 이
GitHub Pages로 자동 배포합니다.

## Fusion 360 애드인 (`fusion360_addin/`)

설치: `Shift + S` (스크립트 및 애드인) → **Add-Ins** 탭 → 초록색 **+** →
해당 폴더 선택 → **Run**. Design 워크스페이스의 SOLID → CREATE 패널에
버튼이 추가됩니다.

| 폴더 | 생성 대상 | 주요 입력 | 제작 |
|---|---|---|---|
| `HarmonicDriveGenerator` | 하모닉 드라이브 3부품 (서큘러스플라인 / 플렉스스플라인 / 웨이브제너레이터 캠) | 모듈, `zf`, `zc`, 벽 두께, 폭 + 고급(ha\*, hd\*, w0\*, α0, 이 두께비, 필렛, 공차) | 이 저장소 |
| `CycloidalGearGenerator` | 사이클로이드 핀휠 감속기 (디스크 / 편심축 / 핀) | 감속비, R, Rr, E, 두께, 부위별 공차 | 별도 제작자 (원본 그대로 포함) |
| `UniversalGearGenerator` | 평 / 헬리컬 / 내치 / 베벨 / 웜 / 웜휠 / 랙 7종 | 기어 종류, 감속비, 모듈 | Antigravity CAD AI (원본 그대로 포함) |

`HarmonicDriveGenerator` 는 웹 버전과 **완전히 동일한 수학 엔진**을 씁니다
(`web/core-math.js` ↔ `fusion360_addin/HarmonicDriveGenerator/hd_math.py`,
서로 포팅 관계). 입력창에는 감속비·피치반경·WG 장단축·스트로크 여유 등이
실시간으로 표시되고, CS 마운팅 홀 / FS 출력 홀도 옵션으로 뚫을 수 있습니다.

각 애드인 폴더의 `README.md` 에 더 자세한 사용법과 검증 내역이 있습니다.

## 검증

하모닉 드라이브 엔진은 같은 논문을 독립적으로 구현한 공개 도구
[Robrotics Harmonic Maker](https://robrotics.web.app/gearmaker) 가 표시하는
수치와 대조해서 확인했습니다. 동일 입력(m 1.25, zf 100, zc 102, w0\* 1.0,
ha\*/hd\* 1.0, α0 9.17°, 필렛 0.15, 공차 0.05)에 대해:

| 항목 | 이 저장소 | 대조 도구 |
|---|---|---|
| 외경 | 136.126 mm | 136.1 mm |
| 이끝 반경 (유도값) | 0.5731 mm | 0.573 mm |
| 백래시 | 0.126 mm | ≈0.127 mm |
| 플렉스스플라인 변형률 | 0.036 % | ≈0.04 % |
| 스트로크 여유 | 49.9 µm | 50 µm |
| 맞물린 이 개수 | 14 (14 %) | ≈14 (14 %) |

수치 샘플링 정밀도 범위 내에서 일치합니다. 파형발생기 타원 단축 `b` 의
닫힌 해도 논문의 설계 예제값(48.2474 mm)과 소수 4자리까지 일치합니다.

## 알려진 한계

- **하모닉 드라이브**: 플렉스스플라인은 치형 링으로만 생성되며 실제 컵
  (다이어프램 + 보스) 형상은 포함하지 않습니다. 웨이브제너레이터는 볼베어링
  레이스가 없는 순수 타원 캠입니다. 백래시·변형률·맞물림 개수는 1차 기하학적
  추정치이며 탄성 해석 결과가 아닙니다. Fusion 쪽 기본 정밀도(치형 샘플 수,
  공액 계산 해상도)는 웹보다 낮게 설정돼 있습니다 — 점 하나가 개별 Fusion API
  호출이라 스케치 곡선 수가 생성 시간을 지배하기 때문입니다.
- **사이클로이드**: 애드인은 핀만 만들고 하우징은 만들지 않으며, 조인트
  자동 생성도 제외했습니다 (과구속 위험). 디스크–핀 공차를 0으로 두면 이론
  포락선이라 디스크가 모든 핀에 동시 접촉해 회전하지 않습니다 — 반드시
  양수로 두세요.
- **범용 기어**: 웹은 인벌류트로 정확히 그리지만 항상 2D이고, 애드인 쪽은
  생성 안정성을 우선한 단순 치형 근사를 씁니다 (해당 폴더 README 참고).
- **웹 전반**: DXF는 2D 프로파일이므로 CAD에서 원하는 두께로 돌출해야 합니다.

생성된 형상은 모두 개념 검증용 기하 데이터입니다. 실제 제작 전에는 강도 ·
탄성 · 공차 검증이 반드시 필요합니다.

## 참고

구성 방식은 위 Robrotics Harmonic Maker 의 접근 방식을 참고해 **독자적으로
