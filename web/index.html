하모닉 드라이브 생성기CTP

사이클로이드 치형 하모닉 드라이브(서큘러스플라인 + 플렉스스플라인 + 웨이브제너레이터 캠)를 실제 envelope 방식 공액 치형 계산으로 생성합니다.

고급 설정

계산 결과

성능 지표 (1차 추정)

Yao et al., "A Novel Cycloid Tooth Profile for Harmonic Drive with Fully Conjugate Features", Actuators 2025, 14(4), 187 의 사이클로이드 치형(Eq. 9–13)과 이빨각 α0 절단(Sec. 3.3)을 그대로 구현하고, 서큘러스플라인 치형은 실제 수치 envelope(Eq. 14–15, 파형발생기 한 바퀴 스윕에 대한 최대반경 래스터화)로 계산합니다 — 근사식이 아닙니다. 백래시·변형률·맞물림 개수는 1차 기하학적 추정치입니다. 생성된 형상은 개념 검증용 기하 데이터이며, 실제 제작 전 반드시 강도/탄성/공차 검증이 필요합니다. Fusion 360 애드인: fusion360_addin/HarmonicDriveGenerator.

고급 설정

계산 결과

포락선(envelope) 방식 사이클로이드 치형입니다. 편심량이 0이면 디스크가 모든 핀에 동시 접촉(이론 포락선)해 끼므로 실제 회전을 위해선 디스크-핀 공차를 양수로 두어야 합니다 (기본 0.1mm). 곡선 부호 규약·공차·베어링 끼워맞춤은 출처/규격마다 다르니 제작 전 검증이 필요합니다.
