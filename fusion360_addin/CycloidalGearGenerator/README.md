# 사이클로이드 감속기 생성기 — Fusion 애드인

사이클로이드 감속기 부품(디스크 · 편심 축 · 핀)을 Autodesk Fusion 안에서
파라메트릭하게 생성합니다. 각 부품은 별도 컴포넌트로, 조립 위치에 배치됩니다.

## 이번 버전(1.7.0)의 특징

- **핀만 생성 (단순형)**: 핀 피치원 R 위에 핀 N개를 균등 배치합니다. 하우징은
  만들지 않습니다(필요하면 Fusion에서 직접 추가). 핀 길이 여유 조절 가능.
- **부위별 개별 공차**: 디스크-핀 / 보어 / 출력 구멍 / 핀 공차를 따로 줍니다.
  - 디스크-핀 공차(핵심): 디스크 외곽선을 살짝 줄여 핀에 끼지 않게 함.
    공차 0이면 디스크가 모든 핀에 동시 접촉(이론 포락선)해 끼므로, 회전시키려면
    반드시 양수로 두세요(기본 0.1mm).
  - 보어 / 출력 구멍 / 핀 공차: 각 반경에 더해짐.
- **별도 컴포넌트 생성**: 디스크/축/핀이 각각 컴포넌트로 생성돼 조립·간섭
  확인이 쉽습니다.
- 기존: 2단 디스크(180도 위상), 편심 축, 성능 최적화, 언어 자동 전환(한/영),
  완전구속, 감속비 입력.

> 조인트 자동 생성은 제외했습니다. 사이클로이드 기구는 디스크가 회전+편심
> 병진을 동시에 하는 복합 운동이라, 조인트를 코드로 걸면 과구속/오정렬이
> 나기 쉽고 조인트 API도 버전 의존적이기 때문입니다. 부품을 정확한 위치에
> 두고 아래 절차로 직접 확인하는 편이 안정적입니다.

## 어셈블리에서 "돌아가는지" 확인하는 방법

1. 생성 후 **ASSEMBLE → Contact Set**(또는 Enable All Contact)을 켭니다.
   디스크 외곽선과 핀, 저널과 보어가 접촉으로 인식됩니다.
2. 편심 축에 **회전 조인트**(As-Built Joint, Revolute, Z축)를 직접 하나 겁니다.
3. 조인트를 **드래그**하거나 **Drive Joints**로 회전 → 디스크가 핀을 따라
   구르는지 확인합니다.
4. 더 정밀하게는 **Motion Study**로 입력축 회전을 입력하고 재생합니다.
5. 간섭이 보이면 디스크-핀 공차를 키워 다시 생성하세요.

처음엔 감속비를 작게(핀 수 적게) 잡아 가볍게 확인하길 권합니다 — Contact Set
시뮬레이션은 계산 부하가 큽니다.

## 설치 / 실행

1. `CycloidalGear` 폴더를 AddIns 디렉터리에 복사
   (Win: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\`).
2. `Shift+S` → 추가 기능 → CycloidalGear → 실행. (언어 변경 후엔 Stop→Run)
3. **솔리드 → 만들기 → 사이클로이드 감속기**.

## 파라미터

| 그룹 | 입력 | 의미 |
|------|------|------|
| 기본 | 감속비 / R / Rr / E / 두께 / 해상도 / 완전구속 | 외곽선·디스크. |
| 디스크 | 보어 생성+지름 / 출력핀 구멍(개수·PCD·핀지름) | 디스크 피처. |
| 2단 | 2단 디스크 + 사이 간격 | 180도 위상 적층. |
| 편심 축 | 생성 / 중앙축 지름 / 저널 지름 / 위·아래 연장 | 입력축. |
| 핀 | 핀 생성 / 핀 길이 여유 | 핀만 생성. |
| 공차 | 디스크-핀 / 보어 / 출력구멍 / 핀 | 부위별 틈새. |

## 검증 요약 (수치 검증 완료)

- 디스크-핀 간극(공차 0.1mm): 0.1mm → 안 끼고 회전 가능.
- 핀 12개 서로 안 겹침(중심거리 15.5 > 6.0), 핀 길이가 디스크 스택 전체 커버.
- 저널 7.0 < 보어 7.5(여유 0.5) / 중앙축 5.5 <= 보어-E 6.0 → 축 정합.
- 2단 위상 상쇄, 출력핀 구멍 배치, z 적층 정합 모두 확인.
- Contact Set 모션은 Fusion 런타임 의존이라 미검증(직접 확인 필요).

## 주의사항

- 곡선 부호 규약·"구멍=핀+2E" 규칙·공차·베어링 끼워맞춤은 출처/규격마다 다름.
- 공차 0이면 디스크가 핀에 끼어 회전 불가 — 디스크-핀 공차는 양수 유지.
- 편심량 E가 R/N 대비 너무 크면 외곽선 자기교차 가능.
- 언어 enum(`KoreanLanguage`)은 가정값, 틀리면 영어 폴백.
